# footage

Drop event clips (`.mp4`, `.mov`, `.webm`) and stills (`.jpg`, `.png`) here and
pass the file name as `footageUrl`. Everything in this folder except this file
is git-ignored: it is large, and it shows real people.

Best results: vertical or square, 3–10s, shot with flash, faces in the middle
third, people who have agreed to appear in ads.
